# 🛍️ Retail Pulse — Retail Sales Analytics Dashboard

**Retail Pulse** is a retail analytics project designed to help users explore sales data, identify business trends, and gain insights that can support data-driven decision-making.

The project includes an interactive dashboard and supporting resources for retail sales analysis.

## 📌 Project Overview

Retail Pulse aims to make retail data easier to understand by presenting business information through a dashboard. Retail analytics can help businesses monitor performance, identify trends, and make informed decisions about sales and inventory.

## ✨ Features

- 📊 Interactive retail analytics dashboard
- 📈 Visual exploration of retail sales data
- 🔍 Business trend analysis
- 💡 Data-driven insights to support retail decisions
- 🖥️ Web-based dashboard interface

*Note: The features available depend on the current implementation and configured data sources.*

## 🛠️ Technology Stack

- **Frontend:** JavaScript and Vite-based development environment
- **Package Management:** npm
- **Data Analysis:** Retail sales data and supporting analysis resources
- **Database:** MySQL resources are included in the project

## ⚙️ Installation and Setup

### Prerequisites

Install the following tools:

- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/)

### 1. Clone the Repository

```bash
git clone https://github.com/manika-29/Retail-Pulse.git
```

### 2. Navigate to the Project Directory

```bash
cd Retail-Pulse
```

### 3. Install Dependencies

Install the root project dependencies:

```bash
npm install
```

Install the dashboard dependencies:

```bash
cd dashboard
npm install
```

### 4. Run the Dashboard

From the `dashboard` directory, execute:

```bash
npm run dev
```

Alternatively, return to the project root and run:

```bash
npm run dev
```

### 5. Open the Application

Open the local URL displayed in your terminal, typically:

```text
http://localhost:5173/
```
